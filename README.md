# MDOS T-72
Дисковая операционная система МикроДОС с базовой системой ввода-вывода версии Т-72 для ПК <b>Вектор-06ц</b>.
Поддерживает два НГМД, два квази-диска и НЖМД.<br>
Является доработанной и улучшенной версией [ОС Т-72](https://caglrc.cc/scalar/ware/630/) (Автор: Центр «Тень»,  Терентьев С.В., 1995 г.).
Подробнее о системе [тут](https://zx-pk.ru/threads/9488-vektor-06ts-operatsionnye-sistemy.html).

Для сборки из исходников требуется компилятор [TASM](http://old-dos.ru/index.php?page=files&mode=files&do=show&id=1385) и упаковщик [LZO28](https://zx-pk.ru/threads/29679-szhatie-dannykh.html?p=1231990&viewfull=1#post1231990).

Бинарные файлы откомпилированы в вариантах:<br>
os-t72f.rom -- без поддержки жёсткого диска<br>
os-t72h.rom -- без поддержки флоповодов<br>
os-t72k.rom -- только квазидиск (один или два)<br>
os-t72hx.rom -- всё оборудование

## Замечания
Из-за невозможности одновременной работы обоих квази-дисков, при обращении из внешних программ к квази-диску 2 (порт 11h) при помощи функции 0E212h (обмен с дисковыми устройствами) адрес буфера в описателе дисковой операции не должен попадать в область экрана 0A000h..0DFFFh. По той же причине размер запускаемой программы МикроДОС или CP/M со второго квази-диска ограничен 40кБ, но это ограничение не касается запуска ROM-программ для Вектора, т.к. они будут считаны полностью в ОЗУ.
